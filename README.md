O repositório está organizado em pastas individuais para cada exercício da lista:

- `exercicio02/`: Verificador de idade (Maior ou menor de idade)
- `exercicio03/`: Antecessor e sucessor de um número inteiro
- `exercicio04/`: Conversor de temperatura (Celsius para Fahrenheit)
- `exercicio05/`: Calculadora de média escolar com verificação de aprovação
- `exercicio06/`: Calculadora de quatro operações básicas com validação de divisão por zero

- `exercicio08/`: Consumo de combustível e classificação de eficiência
- `exercicio09/`: Sistema simples de vendas com aplicação de desconto condicional
- `exercicio10/`: Controle de estoque com operações de entrada, saída e validação de limites
